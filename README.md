# 8-MW wind turbine tower computational shell buckling benchmark. Part 3: Software survey

This international exercise compares finite element predictions for the same multi-strake wind turbine tower segment under two load cases. It builds on the blind round-robin of [Part 1](https://doi.org/10.1016/j.engfailanal.2023.107124) and the detailed reference solution of [Part 2](https://doi.org/10.1016/j.engfailanal.2023.107133). For Part 3, participants had access to the reference solution and documented the software, modelling choices and solvers used to obtain their results.

## Benchmark materials

1. [Benchmark brief (PDF)](<RR3 Tower FE Benchmark - Brief 060924 V3.pdf>) — Start here for the tower geometry, material, loading, boundary conditions, imperfections and analyses requested.
2. [Questionnaire and submission template (Excel)](<RR3 Tower FE Benchmark - Questionnaire & submission template 060924 V2.xlsx>) — The original blank workbook. The Questionnaire sheet records the software and modelling details. The analysis sheets specify the results to report for each load case and solver variant.

The benchmark brief is Version 3 (revised 2026). The questionnaire and submission template remains Version 2, released on 6 September 2024.
